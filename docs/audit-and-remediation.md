## Intentionally open before real use

- Payments, identities, fraud labels, exposure, service telemetry and latency are synthetic or modelled.
- Demo role headers illustrate an authorisation contract; they are not authentication. A real service requires OIDC/workload identity, policy enforcement and privileged-access controls.
- The decision store is process-local. The AWS design uses DynamoDB with point-in-time recovery, but that target is not provisioned by this repository.
- Relationship data is a small fixed fixture. Production traversal needs source provenance, temporal decay, abuse monitoring and performance tests on representative graph density.
- The threshold scenario is illustrative. It is not a calibrated live queue forecast.
- Automated checks do not replace a manual WCAG 2.2 AA audit with assistive technology.
- The million-event generator tests reproducibility and capacity-aware comparison, not generalisation to a bank population.
- Synthetic latency is not a controlled cloud load test, and detected exposure is not recovered cash.

These limitations are kept visible because removing them from the narrative would make the project less credible, not more complete.
